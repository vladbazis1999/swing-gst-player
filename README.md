# GStreamer Swing Video Player

Десктопный видеоплеер на базе **Java Swing** и мультимедийного фреймворка **GStreamer** с функцией автоматического покадрового логирования в базу данных **SQLite**.

## Основные возможности

* **Воспроизведение видео:** открытие локальных файлов (`.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.flv`) через стандартный системный проводник.
* **Управление потоком:** запуск, постановка на паузу, полная остановка со сбросом позиции на `00:00`, интерактивная перемотка по слайдеру с отображением тайминга и регулировка громкости.
* **Автоматическое логирование кадров в SQLite:** при открытии видеофайла (например, `video.mp4`) в той же директории автоматически создается база данных `video.db`. При отрисовке каждого нового кадра фиксируется системное время в формате **Unix time (миллисекунды)** и сохраняется в БД.
* **Архитектура MVC и гибкая конфигурация:** четкое разделение ответственности между слоями приложения и вынос путей нативных библиотек во внешний файл `config.properties`.

## Архитектура проекта

Проект организован в пакете `org.player.soft` по паттерну **MVC**:

* **`Main.java`** — точка входа в приложение. Запускает инициализацию GStreamer, применяет системную тему оформления (Look and Feel) и собирает компоненты MVC в потоке обработки событий Swing (`EDT`).
* **`GStreamerInitializer.java`** — инфраструктурный класс для подготовки окружения. Загружает пути из `config.properties`, настраивает `jna.library.path` и `gstreamer.plugin.path`, предзагружает базовые `.dll` библиотеки (для Windows) и инициализирует ядро GStreamer.
* **`PlayerView.java` (View)** — графический интерфейс (`JFrame`), содержащий область вывода видео (`GstVideoComponent`), кнопки управления, интерактивный таймлайн и регулятор громкости.
* **`PlayerController.java` (Controller)** — связующее звено между интерфейсом, движком `PlayBin` и базой данных. Обрабатывает действия пользователя, обновляет таймлайн по таймеру, слушает события шины `Bus` и перехватывает кадры через `AppSink`.
* **`FrameLoggerRepository.java` (Model / Repository)** — слой работы с SQLite. Отвечает за создание файла `<имя_видео>.db` рядом с открытым роликом, инициализацию таблицы логов и запись временных меток кадров.

## Требования к окружению

1. **JDK 17 или выше** (убедитесь, что в `Main.java` не используются фичи превью-версий).
2. **GStreamer Runtime** версии **1.20 или выше** (например, MSVC 64-bit для Windows).
3. **Зависимости проекта (Maven / Gradle):**
   * `org.freedesktop.gstreamer:gst1-java-core`
   * `org.freedesktop.gstreamer:gst1-java-swing`
   * `org.xerial:sqlite-jdbc`

## Настройка конфигурации (`config.properties`)

Перед запуском проекта необходимо настроить пути к установленному GStreamer. Приложение ищет файл `config.properties` в двух местах (в порядке приоритета):
1. В рабочей директории запуска (рядом с `pom.xml` или собранным `.jar`-файлом).
2. В папке ресурсов проекта (`src/main/resources/config.properties`).

Создайте или отредактируйте файл `config.properties`, указав ваши пути:

```properties
# Путь к исполняемым файлам и нативным библиотекам GStreamer (bin)
gstreamer.bin.path=C:\\Program Files\\gstreamer\\1.0\\msvc_x86_64\\bin

# Путь к плагинам и кодекам GStreamer
gstreamer.plugins.path=C:\\Program Files\\gstreamer\\1.0\\msvc_x86_64\\lib\\gstreamer-1.0

# Список базовых DLL для принудительной предзагрузки в Windows (через запятую)
# Для Linux/macOS этот параметр можно оставить пустым
gstreamer.core.libs=intl-8.dll,ffi-7.dll,glib-2.0-0.dll,gobject-2.0-0.dll,gmodule-2.0-0.dll,gstreamer-1.0-0.dll,gstbase-1.0-0.dll,gstapp-1.0-0.dll
```

*(Примечание: в Windows используйте двойные обратные слеши `\\` или обычные прямые слеши `/`).*

## Запуск и использование

1. Склонируйте репозиторий и откройте проект в IDE (IntelliJ IDEA / Eclipse).
2. Подтяните зависимости через систему сборки (Maven/Gradle).
3. Настройте `config.properties` согласно инструкции выше.
4. Запустите метод `main` в классе `org.player.soft.Main`.
5. Нажмите кнопку **«Открыть»** и выберите видеофайл — рядом с ним автоматически появится файл `<имя_файла>.db`, в который начнут записываться таймкоды кадров.
6. При закрытии окна приложение корректно останавливает таймер, освобождает нативные ресурсы GStreamer (`dispose`) и закрывает соединение с SQLite.
